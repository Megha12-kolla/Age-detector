# 🎂 Age Detector

A simple Python command-line application that calculates a user's age in **years, months, and days** based on their date of birth and the current date entered by the user.

## 🌟 Features

* 📅 Accepts the user's date of birth.
* 🗓️ Accepts the current date.
* 🧮 Calculates the user's age in years, months, and days.
* 🔄 Handles month and day adjustments when needed.
* 💻 Displays the result in a clear and readable format.

## 🛠️ Technologies Used

* Python 3

## ▶️ How to Run

1. Make sure Python 3 is installed.
2. Open a terminal in the project folder.
3. Run the program using:

```bash
python age_detector.py
```

## ⚠️ Limitations

* Assumes every month has **30 days** for simplicity.
* Does not automatically use the system's current date.
* Does not validate invalid dates (for example, 31 February).
